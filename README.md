# 📐 Математика · Уроки 2–11 — классные и домашние работы + тренажёр

Одностраничный сайт (без сервера и без оплаты — GitHub Pages):

* **Классные (К-*) и домашние (Д-*) работы по урокам 2–11** — с проверкой
  ответов прямо на странице (верно — зелёным, ошибка — красным);
* **Интерактивный тренажёр** — задания из уроков 5 и 6 со статистикой
  и баллами (из 20);
* **Отправка результатов учителю в Telegram** — с каждой работы и из
  тренажёра (кнопка «Отправить 📩» + автоотправка при показе результата).

Для учеников на сайте доступны **только классные и домашние работы**.
Листы ответов и решения (`answers.html`) НЕ публикуются — они остаются
у учителя (в старом репозитории `fork-empty-notebook-04`).

## 📩 Отправка результатов (Telegram) — как настроено

Всё уже настроено и работает: отчёты приходят боту **@zverochek_bot**.

Токен и chat_id лежат в **`config.js`** — единственном месте для ключей.
Если понадобится сменить бота:

1. @BotFather → `/newbot` → новый токен → вписать в `botToken`;
2. написать новому боту `/start`;
3. открыть `https://api.telegram.org/bot<ТОКЕН>/getUpdates` →
   `"chat":{"id": ...}` → вписать в `chatId`;
4. закоммитить `config.js` в репозиторий.

Дополнительно поддерживаются **EmailJS** и **Formspree** (письма на почту) —
ключи вписываются в тот же `config.js`; инструкция — в комментарии к файлу.

### Что приходит учителю

Текстовый отчёт: название работы, имя ученика, дата/время, итог
«X из N верно», баллы, построчно все ответы с ✓/✗ и правильными
ответами при ошибках.

### Как это работает на страницах уроков

* На слайде «Результат» появляется блок «📩 Отправить результаты учителю»:
  поле имени + кнопка. Имя сохраняется в браузере (`localStorage`) и
  подставляется на всех страницах автоматически.
* При нажатии «Показать результат 📊» отчёт уходит **автоматически**
  (если имя уже известно) — дублирующая кнопка «Отправить 📩» рядом.
* Нет интернета/ключей — понятная подсказка в консоли (F12) и статусе.

## ▶️ Как запустить локально

Статический сайт — просто открой `index.html` в браузере.
Для «серверного» варианта:

```bash
cd trenazhor
python3 -m http.server 8000   # → http://localhost:8000
```

## ✏️ Как менять задания и оформление

* **Задания тренажёра** — `tasks.js` (формат описан комментарием
  в начале файла: копируешь блок `question`, меняешь текст и ответы).
* **Задания уроков** — правь нужный `lessonN/classwork.html` (или
  `homework.html`): ответы лежат прямо в полях `data-a="..."`,
  группы баллов — `data-g` и `data-w`.
* **Оформление** — `style.css`, блок `:root` (все цвета в 7 строках).
* **Добавить новый урок** — скопируй папку `lessonN` из
  `fork-empty-notebook-04` (только `classwork.html` и `homework.html`),
  добавь два `<script>` перед `</body>` (см. любой существующий урок)
  и строку-карточку в `index.html`.

## 🔒 Про токены

* Токен бота лежит в открытом репозитории — это нормально для
  бесплатного статического сайта; при спаме сделай `/revoke`
  в @BotFather и обнови `config.js`.
* **GitHub-токен (PAT) после настройки нужно удалить**: GitHub →
  Settings → Developer settings → Personal access tokens. Для обычных
  правок используй веб-интерфейс GitHub (Add file → Upload files).

## 📱 Управление на уроке

* **Enter** — проверить задание, **← →** — листать, на телефоне — свайп.
* Кнопка «Завершить и посмотреть результаты» (тренажёр) доступна в любой
  момент — непроверенные поля попадут в отчёт как «без ответа».
* Имя ученика вводится один раз — дальше подставляется само.
