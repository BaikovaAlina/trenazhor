# 📐 Тренажёр по математике · Уроки 5–6

Одностраничный сайт с интерактивными упражнениями: ученик вводит имя,
выбирает вариант (К-5, Д-5, К-6, Д-6), решает задания с проверкой
«верно/неверно», видит итоговую статистику, а результат отправляется
учителю (Telegram / EmailJS / Formspree) или скачивается файлом.

Сайт работает **без сервера и без оплаты** — статическая страница
на GitHub Pages. Внешних фреймворков нет: чистый HTML + CSS + JS.

---

## 📁 Файлы

| Файл | Что внутри |
|---|---|
| `index.html` | Разметка: три экрана (старт → задания → результаты) |
| `style.css` | Оформление «тетрадь в клетку» (как на страницах уроков) |
| `script.js` | Логика + **блок CONFIG** (отправка результатов) |
| `tasks.js` | **Все задания и ответы** (легко редактировать) |

---

## ▶️ Как запустить локально

Специального сервера не нужно — страница статическая.

1. Скачай файлы в одну папку.
2. Открой `index.html` двойным кликом в браузере — готово.

Если хочется через локальный сервер (например, для проверки):

```bash
cd папка-с-сайтом
python3 -m http.server 8000
# откроется на http://localhost:8000
```

## ✏️ Как поменять задания и ответы

Все задания лежат в `tasks.js` — в самом начале файла подробный
комментарий с описанием формата. Кратко:

```js
const TASKS = {
  "K-5": {                       // ключ варианта
    title: "Урок 5 · Классная работа",
    topic: "Закономерности и паттерны",
    questions: [
      {
        num: "1",                                  // номер задания
        title: "Ответьте устно",                   // заголовок
        sub: "— каждый верный ответ 0,5 балла",    // пояснение (можно "")
        crumb: "Урок 5 · разминка",                // надпись сверху (можно "")
        hints: ["Где два числа — пиши каждое в своё поле."],  // подсказки []
        tasks: [                                   // строки (подпункты а, б, в…)
          {
            label: "а) 2; 5; 8; 11; …",
            parts: [                               // раскладка строки:
              "а) 2; 5; 8; 11; …",                 //   текст
              { "_input": 0 },                     //   поле ввода (№0)
              ";",                                 //   текст
              { "_input": 1 },                     //   поле ввода (№1)
            ],
            inputs: [
              { a: "14",  type: "", g: "1а", w: 0.5 },  // ответ, тип, группа, вес
              { a: "17",  type: "", g: "1а", w: 0.5 },
            ],
          },
        ],
      },
    ],
  },
};
```

### Параметры поля (`inputs[N]`)

| Поле | Смысл |
|---|---|
| `a` | Правильный ответ. Несколько допустимых вариантов — через `\|`: `"да\|yes"` |
| `type` | `""` — обычное поле; `"list"` — список чисел через запятую (порядок не важен: `10,11,12` = `12,10,11`) |
| `g` | Группа оценивания: балл начисляется, только если **все** поля группы верны |
| `w` | Вес группы в баллах (в сумме по варианту — 20; бонусные задания — `w: 0`) |

### Как добавить/удалить задание

* **Добавить** — скопируй блок `question` в массив `questions`, поправь
  `num`, `title`, `tasks`. В `parts` ставь маркеры `{"_input": N}` ровно
  в тех местах, где должно быть поле; N — номер элемента в `inputs`.
* **Удалить** — вырежи блок `question` целиком.

## 🎨 Как поменять оформление

Всё в `style.css`, в блоке `:root` — цвета одной строкой:

```css
--paper:#FBF7EC;   /* цвет бумаги */
--grid:#C9D9E8;    /* линии клетки */
--red:#E2574C;     /* поля, номера, поля ввода */
--chalk:#2E5D4B;   /* доска и заголовки */
--sticky:#FFF3B0;  /* стикеры */
--green:#1f7a4d;   /* верный ответ */
```

Шрифт задан в `body{font-family:...}` — сейчас «Segoe Print / Comic Sans»
(рукописный стиль тетради). Отступы карточки — `.slide{padding:...}`.

## 📩 Отправка результатов учителю (всё бесплатно!)

Открой `script.js` → самый верх, блок **`CONFIG`**. Заполни **хотя бы один**
канал — отправка будет идти по всем заполненным сразу. Если ключей нет —
в консоли браузера будет понятная ошибка-подсказка, а ученик сможет
скачать отчёт кнопкой «Скачать отчёт (.txt)».

### Вариант 1 · Telegram (без ограничений, рекомендую)

1. В Telegram напиши **@BotFather** → команда `/newbot` → придумай имя.
2. BotFather пришлёт **токен** вида `123456789:AA...` — впиши в `botToken`.
3. Напиши **своему новому боту** любое сообщение (чтобы он тебя «увидел»).
4. Узнай `chat_id`: открой в браузере  
   `https://api.telegram.org/bot<ТОКЕН>/getUpdates`  
   и найди `"chat":{"id": 123456789}` — это `chat_id`.
5. Впиши в CONFIG:

```js
telegram: {
  botToken: "123456789:AA...",
  chatId:   "123456789",
},
```

Готово: каждый результат придёт боту сообщением.

### Вариант 2 · EmailJS (письма на почту, 200 писем/мес)

1. Зарегистрируйся на [emailjs.com](https://www.emailjs.com) (бесплатно).
2. **Email Services** → *Add New Service* → свяжи свою почту → получишь **Service ID**.
3. **Email Templates** → *Create New Template*:
   * в поле *To Email* поставь свою почту (кому писать);
   * в теле письма напиши, например:  
     `Ученик: {{from_name}}` и вставь `{{message}}` — сюда придёт весь отчёт.
4. **Account → API Keys** → скопируй **Public Key**.
5. Впиши в CONFIG:

```js
emailjs: {
  serviceId:  "service_xxxxxxx",
  templateId: "template_xxxxxxx",
  publicKey:  "AbCdEf...",
},
```

### Вариант 3 · Formspree (письма на почту, 50 писем/мес)

1. Зарегистрируйся на [formspree.io](https://formspree.io) (бесплатно).
2. *New Form* → любое имя → получишь **endpoint** вида  
   `https://formspree.io/f/XXXXXXX`.
3. Письма будут приходить на почту аккаунта Formspree.
4. Впиши в CONFIG:

```js
formspree: {
  endpoint: "https://formspree.io/f/XXXXXXX",
},
```

### Что уходит учителю

Текстовый отчёт: имя ученика, дата/время, вариант, каждый пункт с ответом
ученика, отметки ✓/✗, правильные ответы при ошибках, итог «X из N»
и баллы (из 20), список заданий с ошибками.

## 🌐 Как опубликовать сайт (GitHub Pages, бесплатно)

Сайт лежит в репозитории `trenazhor` и опубликован:

**https://baikovaalina.github.io/trenazhor/**

Обновление после правок:

1. Загрузи изменённые файлы в репозиторий `trenazhor` (через веб-интерфейс
   GitHub: *Add file → Upload files*, или `git push`).
2. GitHub Pages обновит сайт автоматически за ~1 минуту.

Проверь, что Pages включён: *Settings → Pages → Deploy from a branch → main / root*.

## 🔒 Важно про токены

* Токены (`botToken`, `publicKey` и т.д.) — **не секретные** в полном смысле:
  сайт статический, «спрятать» их некуда. Держи бота и Formspree-форму
  только у себя и никому не пересылай ссылку на настройки.
* **GitHub-токен (PAT) больше не используй и отзови**:  
  GitHub → Settings → Developer settings → Personal access tokens → *Delete*.
  Для загрузки файлов используй веб-интерфейс GitHub или создай новый токен
  только когда нужен доступ со скрипта.

## 📱 Управление на уроке

* **Enter** — проверить текущее задание, **← →** — листать, на телефоне — свайп.
* Имя ученика сохраняется в браузере (`localStorage`) — на своём устройстве
  ученик вводит его один раз.
* Кнопка «Завершить и посмотреть результаты» доступна в любой момент —
  непроверенные поля попадут в отчёт как «без ответа».
